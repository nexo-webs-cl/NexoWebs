# Nexo Webs — Sitio Web Oficial

Sitio web corporativo y de presentación de servicios digitales de **Nexo Webs**, estudio boutique enfocado en diseño y desarrollo de sitios web modernos, rápidos y personalizados para pequeños emprendimientos y locales comerciales.

---

## Estructura del Proyecto

- `index.html`: Página principal con presentación de soluciones, catálogo de rubros, metodología, equipo y cotizador interactivo hacia WhatsApp/Email.
- `styles.css`: Estilos visuales optimizados siguiendo el sistema de diseño central.
- `script.js`: Interactividad, scroll suave, acordeón FAQ y cotizador dinámico.
- `design-system/`: Documentación y directrices de diseño visual.
- `LICENSE`: Términos de propiedad intelectual y derechos reservados.
